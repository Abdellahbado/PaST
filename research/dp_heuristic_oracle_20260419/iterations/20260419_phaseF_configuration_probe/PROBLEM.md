# Problem

Phase F question:

- is a rate-class configuration master with exact DP pricing viable and correct in regime 1?

Bounded scope:

- regime 1 only
- first target: instance `46`, `epsilon=77`
- only after clean success: at most one or two extra epsilon checks on instance `46`

Success criterion for first probe:

1. implement exact class-count integer master over fully enumerated configurations,
2. solve `46/77` successfully,
3. match exact optimum TEC at that epsilon.

This is a feasibility probe, not a paper-level claim.
